# TapTap 上架文案（可直接粘贴）

**游戏名**：失踪的邻居

**副标题**：她不见了。还是，你不见了？

**类型**：解谜 / 叙事

**一句话介绍**：在空无的公寓里寻找失踪邻居，直到线索开始指回你自己。

**简介（短）**：

林晚音失踪三天。你循着门上的纸条走进她的房间，拼起门禁、日记与监控。越查越像有人在跟踪——直到你发现，被跟踪的人可能是你。一款约 40 分钟的短篇叙事解谜。

**标签建议**：解谜, 叙事, 短篇, 悬疑, 单人

## 素材规格

- 图标 512×512（`icon.png` 已就绪）
- 封面 1920×1080
- 至少 3 张截图（竖屏 9:16，见 `docs/screenshots/`）
- 实机视频建议 20 秒以内

## 上架路径

先建游戏页开「预约」→ 试玩/正式包再补资质；若走 Tap 小游戏正式上线，需前置备案（无内购相对简单）。本项目先按 **APK / TapPlay** 思路导出即可。
