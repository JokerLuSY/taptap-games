# 《炎烬之誓》SRPG 设计标准

完整大纲见 `ember_oath/docs/design.md`。本文件是开发时必须遵守的品质标准与数值约定，改动任何一条都要先同步 design.md。

## 战斗演出标准（火纹的核心，不许做"平庸的打击感"）

普通攻击与暴击必须是**两套完全不同的演出**：

- **普通攻击**：起手式 → 突进 → 命中（白闪+震屏+击退+伤害数字）→ 归位，节奏快（单次 ~0.5s）
- **暴击**：金色蓄力慢动作（单位镀金 0.35s + 中央"必 杀 !"大字弹出）→ 慢速突进（0.3s 压迫感）→ 重击（大震屏 + 双倍火花 + 1.6 倍伤害数字 + 专属暴击音效）
- **打击停顿（hit-stop）**：命中瞬间冻结 0.05~0.1s，这是打击感的关键
- **HP 条必须平滑消减**（tween 0.3s），不许瞬跳

**每种武器的攻击动作必须有性格**（已实现，新武器必须遵守）：

| 武器 | 动作 | 特效 |
|---|---|---|
| 剑 | 快速突进斩击，轻盈 | 弯月斩弧（颜色随使用者发色） |
| 枪 | 先后撤蓄力再长突 | 突刺直线 |
| 斧 | 跃起 40px 再劈落，沉重 | 大震幅 + 斩弧 |
| 弓 | 原地拉弓，箭矢实体飞行 | 命中火花 |

新增角色/武器时，动作、特效颜色、音效都要能体现其身份（如缇娅的斩击带她的红色调）。

## 数值约定

- **暴击**：`必杀率 = 技巧/2 + 武器必杀`，暴击伤害 ×3；战斗预报面板必须显示必杀率
- **经验**：`10 + (敌Lv−己Lv)×3`（clamp 1~60）+ 击杀 15 + BOSS 25；高级打低级每级 −3 保底 1（保姆骑士机制）
- **支援**：相邻站 1 回合 +1 点，满 6 点解锁 C 级（相邻时双方 命中/回避 +5）；菜单【支援】触发对话，解锁后永久生效
- **说得**：特定我方单位与特定敌人相邻出现【说得】，对话后敌人转我方，当回合不可行动
- **高度**：攀爬每层 +2 移动力；居高临下 +10 命中 +1 伤害；弓箭手 Lv2 射程 +1
- **战斗公式**：伤害 = 威力+力−守备−地形；命中 = 武器命中+技×2±相克×10−敌速×2−地形回避；速差 ≥4 追击；剑克斧、斧克枪、枪克剑

## 美术标准

- 地形底色用 AI 手绘纹理（`ember_oath/tools/process_terrain.py` 处理成 64px×4 旋转变体），禁止平涂纯色
- **整图模式（当前方案）**：`art/maps/ch1_bg.png` 为 AI 手绘底图，逻辑网格向手绘对齐（勿改格子去迁就程序绘制）。
  道路/桥/河流/崖壁/沙滩/森林/麦田全交给手绘；**物件（房/井/山精灵、农田色块、波光）全部运行时叠加**。
  修改地图布局后必须检查与手绘是否错位（桥在第 5 列、崖壁格='X' 不可通行）
- **抠图纪律（`tools/process_sprites.py`）**：AI 白底素材必须过"二值抠白(≥232)+近白中性阴影抠除+1px 腐蚀+
  重采样后 fringe 清理(半透明白→全透, 低alpha暗残→全透)+底部接触暗边"，缩放后不允许任何半透明白像素残留；
  生成新素材时要求"白底、无地面阴影、深色描边"，否则阴影和白底混色无法安全抠除
- **补图纪律（`tools/compose_map.py`）**：抹除背景里的彩绘物件一律"整块连贯复制"（源=同横带干净区或已补好区域），
  禁止小样块平铺（会产生方格接缝）；补丁源区必须先用 `tools/verify_sources.py` 核验干净；补完用
  `tools/zoom_bg.py`+`detect_residual.py` 目检复查
- **落位阴影**：精灵底部必须画双层压扁椭圆阴影（内浓外淡），无阴影=悬浮穿模感
- 地图必须有 2.5D 感：高度差自动生成悬崖立面（岩壁纹理+草唇+垂草），水边有泡沫/芦苇/睡莲
- 单位为 GBA 风 Q 版：3/4 视角（发团盖头顶露下半脸）、深色描边、阴阳面、待机浮动（相位错开）
- 色调偏 GBA 低饱和暖色，全局 5% 暖色滤镜
- 音效用 `ember_oath/tools/generate_audio.py` 程序合成（8-bit 芯片风），BGM 同理

## 工程纪律

- **任何改动后必须跑冒烟测试**：`godot --path ember_oath res://tools/smoke_runner.tscn`（无头验证逻辑，窗口模式出截图），ALL PASS 才算完成
- 新系统必须附带对应的测试断言
- 测试窗口弹出时禁止真实鼠标干扰（已屏蔽 `_unhandled_input`）
- 剧情文本走 `chapter*.gd` 的事件钩子（`play_dialogue`），不要在 battle.gd 里硬编码台词
- 新类加了 `class_name` 后必须先 `--import` 再运行（全局类缓存）
