# 炎烬之誓 · 完整游戏流程（按代码现状整理）

> 本文按 `scripts/` 里的实际实现整理，不是设计愿景。设计大纲见 `design.md`。
> 数值、坐标、台词条数都以代码为准；坐标写作 (列 x, 行 y)，左上角为 (0,0)，地图 15×10、每格 64px。

---

## 0. 场景总览

```
标题 title.tscn
 ├─ 新游戏 ──→ 开场旁白 narration.tscn ──→ 战斗 battle.tscn（第一章）
 ├─ 继续游戏（有存档时才出现）──→ 战斗 battle.tscn（第一章，读检查点）
 ├─ 第二章 ──→ 战斗 battle.tscn（第二章，直接进）
 ├─ 语言切换（中 / 英）
 └─ 菜单（系统菜单：继续、音乐音量、音效音量）

战斗 battle.tscn
 ├─ 胜利 ──→ 结算层「回到标题」
 └─ 战败 ──→ 结算层「重开本关」/「回到标题」
```

- 逻辑分辨率 1280×720 横屏。地图区在左（960×640，顶栏下方 y=48 起），右侧 320px 是信息栏。
- 安全区：左右 64、上下 48；贴边按钮再内缩到 80；所有按钮最小热区 48px。
- 输入统一走 `PointerInput`：鼠标左键 = 触摸点按 = 「确认」；鼠标右键 / Esc / Android 返回 = 「后退」。

## 1. 标题画面（`title.gd`）

**画面**：近黑底色，24 颗橙色余烬粒子从下往上飘（出顶后回到底部随机位置）。中间大字「炎烬之誓」，副标「Emberflame Oath · 战棋原型」。右侧 280×360 金边框里是缇娅立绘。底部小字「第一章 · 边境的少女（原型 v0.1）」。播放地图 BGM。

**按钮**（中间一列，自上而下）：

| 按钮 | 出现条件 | 行为 |
|---|---|---|
| 继续游戏 | `user://save.cfg` 存在 | 标记「待读档」，进入第一章战斗，从检查点那一回合开始 |
| 新游戏 | 总是 | 无存档：直接开始；有存档：弹确认「开始新游戏会覆盖当前存档，确定吗？」→ 确定后删存档 → 开场旁白 |

**后退键**的层级：系统菜单开着 → 关菜单；确认框开着 → 关确认框；都没有 → 打开系统菜单。

## 3. 战斗场景的通用流程（`battle.gd`）

两章共用同一个战斗场景，章节差异全在 `chapter1.gd` / `chapter2.gd` 的数据与事件钩子里。

### 3.1 进场

1. 读取待开章节（标题写入的 `pending_chapter`，空 = 第一章）。
2. 建地图：`Board` 读入章节的 ASCII `MAP` 和高度 `LEVELS`，渲染三层——`MapTiles` 静态图块、`MapFx` 水波 / 火苗 / 烟、氛围层（云影、调色、暗角；火场章节压暗偏橙并加余烬粒子）。
3. 有待读档 → 按存档还原单位与旗标，直接进入「待命」；否则按章节 `UNITS` 生成单位，播开场剧情。
4. 播地图 BGM。

### 3.2 屏幕布局

- **顶栏**：章节名 ·「第 N 回合 · 我方回合 / 敌方回合」· 金钱；右侧「危险范围 (T)」「回合结束」按钮。
- **右侧信息栏**：顶部常驻胜负条件（「胜利 击败所有敌人」/「败北 缇娅或巴尔托阵亡」）。中间显示光标下的内容：
  - 有单位：立绘（有立绘的角色）+ 名字 / 等级 / 职业 / 阵营、HP / EXP、力技速守移、武器、道具。
  - 空地：【地形名】高度 Lv、守备 / 回避加成。
  - 底部常驻「返回」「菜单」。
- **底部提示条**：随状态变化的操作提示。
- **对话框**：底部停靠，左侧 124px 立绘，名字按角色着色，打字机效果。

### 3.3 回合循环

```
开场剧情 → [我方回合开始] → 我方逐个行动 → 全员行动完（或点「回合结束」）
        → [敌方回合] → 回到 [我方回合开始]（回合数 +1）
任何一次战斗后都检查胜负 → 胜利 / 战败结算
```

**我方回合开始**依次做：
1. 所有存活单位（含敌方）取消「已行动」灰色。
2. 回合数 +1（第一回合除外），横幅「第 N 回合 · 我方回合」，音效 phase。
3. 支援点结算：每个支援对如果此刻相邻，点数 +1；刚好攒满时提示「X 与 Y 的羁绊加深了……（相邻时可用【支援】）」。
4. 章节回合事件（第一章第 2、3 回合有剧情，见后）。
5. 进入「待命」；**仅第一章**此时自动写检查点。

**敌方回合**：
1. 清掉所有高亮与危险范围，横幅「敌方回合」，等 0.9 秒。
2. 按单位列表顺序，每个存活敌人：
   - AI 决策（见 §5）。
   - 光标跳到它身上；若它要移动或攻击，先亮出它的移动范围 0.25 秒。
   - 沿路径走过去（每格 0.09 秒，森林 / 废墟等 2 消耗地形放慢 35%，边走边转身、脚下扬尘）。
   - 有目标就开战（完整战斗演出）。
   - 变灰，间隔 0.3 秒到下一个。
3. 全部行动完 → 下一个我方回合。

### 3.4 我方单位的一次完整行动

```
待命 ──点我方未行动单位──→ 选择移动
选择移动 ──点蓝格──→（走路动画）→ 行动菜单
行动菜单 ──攻击──→ [多武器时] 选武器 → 选目标 → 战斗预报 → 确定 → 战斗演出
         ──访问 / 对话 / 支援 / 说得──→ 剧情 → 结束行动
         ──道具──→ 选道具 → 使用 → 结束行动
         ──待机──→ 结束行动
```

1. **待命**：
   - 点我方未行动单位 → 选中（单位小跳一下）。
   - 点敌人 → 显示它的威胁范围（移动范围 + 移动后能打到的格子，红色）。
   - 点空地 → 清高亮。
   - 按 T 或点「危险范围」→ 开关全体敌人的威胁范围（红色虚线外轮廓）。
2. **选择移动**：蓝色 = 能到的格子，红色 = 移动后能攻击但走不到的格子。光标在蓝格上移动时，从单位脚下画出火纹式路径箭头。
   - 点蓝格 → 沿最短路径走过去。
   - 点另一个未行动的我方单位 → 改选它。
   - 点其他地方 / 后退 → 取消选择。
3. **行动菜单**（贴在单位旁边），按条件出现：

| 选项 | 出现条件 |
|---|---|
| 攻击 | 总是出现；当前位置打不到任何敌人时置灰 |
| 访问 | 站在民居 H 上且这间没访问过 |
| 对话 | 章节判定有可对话的相邻伙伴（第一章缇娅↔巴尔托，仅一次） |
| 支援 | 支援点已攒满且伙伴相邻、尚未解锁 |
| 说得 | 相邻有本单位能招募的敌人 |
| 道具 | 身上有道具 |
| 待机 | 总是 |

   后退 = 撤销移动：单位以 0.6 倍时长沿原路走回起点，重新进入「选择移动」。
4. **攻击**：
   - 有多把武器（巴尔托：银枪 / 投枪）时先选武器，按钮显示「武器名 (攻X 命Y)」，打不到目标的武器置灰。
   - 选目标：只高亮能打到的敌人。
   - 点目标 → **战斗预报**面板，左右两栏各写：名字 Lv 职业、HP、武器、攻击（追击时 ×2）、命中、必杀；防守方无法反击时写「（无法反击）」。确定 / 取消。
5. **战斗结算后**：阵亡单位淡出缩小 0.5 秒 → 我方攻击者（存活时）获得经验并飘字「EXP +N」→ 满 100 升级，弹出升级面板 1.5 秒（逐项「+1」，全没涨写「（能力没有提升……）」）→ 章节战后事件 → 胜负检查 → 单位变灰。
6. 全员行动完：提示「全军行动完毕……」，0.6 秒后自动进入敌方回合。也可随时点「回合结束」提前结束。

**道具**：目前只有伤药（恢复 10 HP，用掉即消失）。绿色飘字「HP +10」，占用本回合行动。

### 3.5 后退键的层级

系统菜单开着 → 关菜单；处在选择移动 / 行动菜单 / 选武器 / 选目标 / 道具菜单，或待命时地图上有高亮 → 后退一层；否则 → 打开系统菜单。剧情、战斗演出、敌方回合中，「返回」按钮不响应。

**系统菜单**打开时暂停整个场景树：继续 / 回到标题 / 音乐音量 / 音效音量（音量存进 `user://settings.cfg`）。

## 4. 战斗规则（`combat.gd`、`game_data.gd`、`board.gd`）

### 4.1 移动

- 四方向 BFS。进入一格的消耗 = 地形消耗 + 爬升层数 ×2（下坡不加价）。
- 敌方单位挡路；友方可以穿过但不能停在其上。
- 守点单位（BOSS）`stationary`：永远不移动。

**地形表**

| 符号 | 地形 | 可走 | 消耗 | 守备 | 回避 |
|---|---|---|---|---|---|
| `.` | 平原 | ✔ | 1 | 0 | 0 |
| `R` | 道路 | ✔ | 1 | 0 | 0 |
| `F` | 森林 | ✔ | 2 | 0 | +10 |
| `H` | 民居 | ✔ | 1 | 0 | +5 |
| `B` | 木桥 | ✔ | 1 | 0 | 0 |
| `f` | 农田 | ✔ | 1 | 0 | 0 |
| `g` | 高地 | ✔ | 1 | 0 | +5 |
| `s` | 沙滩 | ✔ | 1 | 0 | 0 |
| `C` | 焦土 | ✔ | 1 | 0 | 0 |
| `Z` | 废墟 | ✔ | 2 | +1 | +5 |
| `~` 河流 / `M` 山地 / `W` 水井 / `X` 崖壁 / `E` 火焰 | | ✘ | — | — | — |

### 4.2 武器

| 武器 | 类型 | 威力 | 命中 | 必杀 | 射程 |
|---|---|---|---|---|---|
| 铁剑 | 剑 | 5 | 90 | 5 | 1 |
| 炎刃 | 剑 | 7 | 90 | 5 | 1 |
| 银枪 | 枪 | 12 | 80 | 5 | 1 |
| 投枪 | 枪 | 7 | 70 | 0 | 1–2 |
| 铁斧 | 斧 | 7 | 75 | 0 | 1 |
| 战斧 | 斧 | 9 | 65 | 0 | 1 |
| 铁弓 | 弓 | 6 | 80 | 5 | 2 |

- 相克：剑克斧、斧克枪、枪克剑。弓不参与相克。
- 弓手站在高度 ≥2 的格子上，射程 +1（变成 2–3）。
- 防守方自动选一把能打到当前距离的武器反击，没有就不能反击（例如弓手被贴脸、剑士被弓手隔一格射）。

### 4.3 公式

```
伤害 = 威力 + 力 + (克制时 +1) − 对方守备 − 对方脚下地形守备
命中 = 武器命中 + 技×2 + 相克×10 − 对方速×2 − 对方脚下地形回避   (0~100)
居高临下：所在高度更高的一方 命中 +10、伤害 +1
支援加成：已解锁支援的伙伴在相邻格 → 自己命中 +5、对方对自己命中 −5
追击：速度差 ≥4 的一方再打一次
必杀率 = 技/2 + 武器必杀，必杀伤害 ×3
```

- 出手顺序：攻击方 → 防守方反击 → 追击（攻击方速度快 4 以上则攻击方追击，否则防守方快 4 以上则防守方追击）。任一方 HP 归零立即结束。
- 命中和必杀各自独立掷骰。

**经验**

```
基础 = clamp(10 + (对方等级 − 自己等级) × 3, 1, 60)
击杀 +15
自己等级高于对方：每高 1 级 −3，最低 1
```

只有**我方主动攻击**时，攻击者才拿经验。每 100 升一级，各项按成长率逐项掷骰 +1。

### 4.4 典型数值（第一章初始状态、平地）

| 交战 | 攻方伤害 / 命中 / 次数 | 反击伤害 / 命中 / 次数 |
|---|---|---|
| 缇娅（铁剑）→ 山贼 | 9 / 100 / ×2（共 18，山贼 22 血打不死） | 8 / 55 / ×1 |
| 缇娅 → 布洛克 | 6 / 100 / ×1 | 14 / 51 / ×1（两下就能打死 20 血的缇娅） |
| 巴尔托（银枪）→ 山贼 | 18 / 82 / ×2（两下都中就击杀） | 5 / 73 / ×1 |
| 巴尔托（银枪）→ 布洛克 | 15 / 80 / ×2（共 30，布洛克 34 血） | 11 / 69 / ×1 |
| 弓手 → 缇娅（隔一格） | 7 / 76 / ×1 | 无法反击 |

经验参考：缇娅 Lv1 击杀山贼 Lv2 得 28；只打不杀得 13；击杀布洛克 Lv4 得 34。巴尔托 Lv8 打山贼只得 1。

### 4.5 战斗特写演出（`combat_scene.gd`、`combat_fighter.gd`）

每次交战（含敌方回合）都会进入横版特写。角色是原创 GBA 火纹风像素条带（`art/combat/fe/`，由 `tools/pixelart/fe_combat.py` 生成），每套有待机、跑、普攻、必杀、受击、倒地六个动作，普攻和必杀是两套不同的动作。

1. 切到战斗 BGM，白闪；按防守方脚下地形选四层视差背景（草地 / 森林 / 焦土；表里没有的地形默认草地），配环境粒子。
2. 双方从屏幕两侧跑步入场，镜头从右往中间收。
3. 每次出手：
   - **必杀蓄力**：背景压暗（角色不暗）、出手方发金光、大字「必 杀 !」、镜头推近；弓手身前先聚一圈光。
   - 近战跑到对方面前出招，到动作的出手帧才结算；弓手原地拉弓放箭，箭飞到才结算。必杀箭更大、发金光并拖光点。
   - 缇娅的必杀动作带橙色残影，这是主角专属。
   - 命中：顿帧、受击方闪白、震屏（必杀更重并全屏白闪）、火花、伤害数字、击退；HP 条在命中当帧开始掉。
   - 命中特效按角色区分（Ninja Adventure CC0 刀光帧）：

| 角色 | 普攻 | 必杀 |
|---|---|---|
| 缇娅 | 弧形刀光 | 火色大弧斩 + 十字斩 + 光环 |
| 巴尔托 | 斩痕 | 蓝白大弧斩 + 火花爆 |
| 山贼 | 双弧刀光 | 大回旋斩 + 圆斩 |
| 头目（布洛克 / 马尔科） | 大弧刀光 | 脚下爆炸 + 橙色冲击环 + 刀光 |
| 探子 | 斩痕 | 二连斩 + 十字斩 |
| 弓手 | 小光环 | 金色火花爆 + 光环 |

   - 未命中：「MISS」，受击方后撤闪避。
   - 打完后跳归位，压暗和镜头复原。
4. 阵亡方播倒地动作后淡出；整个特写淡出，切回地图 BGM。
- 底部双方面板：名字、武器、HP 数字与带刻度的 HP 条（我方蓝底、敌方红底）；右侧 HIT / DMG / CRT（追击时 DMG 后面带 ×2）。
- 点击 / 回车可跳过演出，直接结算剩余伤害。

## 5. 敌方 AI（`ai.gd`）

- **守点单位**（布洛克、马尔科）：不动，只在原地能打到人时攻击，挑分数最高的目标。
- **普通敌人**：
  1. 枚举自己移动范围内每一格 × 每个我方单位 × 每把武器，计算
     `分数 = 伤害 × 命中/100 + (能一击打死则 +100) − 对方反击伤害 × 0.3`，
     选分数最高的「站位 + 目标」去打。
  2. 哪儿都打不到 → 走到离最近我方单位曼哈顿距离最近的格子，不攻击。
- 用哪把武器：在选好的站位上挑期望伤害最高的。

## 6. 第一章「边境的少女」（`chapter1.gd`）

### 6.1 地图

```

y5   ~~~~~B~~~~~~~~~      ← 河流，唯一的木桥在 (5,5)
```

## 8. 存档与续关（`campaign_save.gd`）

- 单存档位 `user://save.cfg`，**只记录第一章**。
- 每个我方回合开始、回合剧情放完、进入待命时自动写入：章节 id、回合数、金钱、全部单位的完整状态（位置、HP、能力、经验、武器道具、是否行动过、支援关系）、章节旗标（哪些民居访问过、各段剧情放没放过、支援是否解锁）、支援点数。
- 「继续游戏」回到该回合开始，不重播已经放过的剧情。
- 第一章胜利只把存档标记为已通关，单位快照仍停在获胜那一回合的开始——此时「继续游戏」会重打那一回合。
- 「新游戏」确认后删档；战败「重开本关」也会删掉第一章检查点。
- 语言和音量另存在 `user://settings.cfg`，与进度无关。

## 10. 现状与设计不一致 / 待补的地方

整理流程时发现的问题，按影响排序：

0. **第 2 章转职与新大纲冲突**：大纲已改为「所有转职需满 Lv10」，缇娅第 2 章只演火焰初醒、不转职，炎刃使挪到第 5 章「离别」（不满 Lv10 则顺延）。代码仍在第 2 章开场强制转职（§7.3），待改。
1. **两章不衔接**：第一章胜利后只能回标题；第二章随时可从标题进，数值固定，不继承第一章的等级和道具，也不写存档。标题底部仍写「第一章（原型 v0.1）」。
2. **防守不给经验**：只有我方主动攻击时才拿经验，敌方回合被打、反击杀敌都没有经验。
3. **BOSS 额外经验没做**：`design.md` 写击杀 BOSS +25，代码里没有。
4. **金钱没有用处**：只能攒，没有商店或整备。
5. **第二章战斗背景**：焦土 C、废墟 Z 不在地形→背景表里，特写会落到「草地」套；反而木桥 B 映射到了焦土套。
6. **占位素材**：「缇娅·觉醒」用第一章立绘加暖色调；探子、马尔科用山贼立绘；觉醒 / 火焰 / 转职音效和火焰 loop 是静音文件。
7. **`design.md` 的待实现清单过时**：暴击、支援、说得、战斗预报显示必杀率都已经实现，清单里还挂着。
8. 通关后「继续游戏」会重打获胜那一回合（见 §8）。
