# 炎烬之誓 · 完整游戏流程（按代码现状整理）

> 本文按 `scripts/` 里的实际实现整理，不是设计愿景。设计大纲见 `design.md`。
> 数值、坐标、台词条数都以代码为准；坐标写作 (列 x, 行 y)，左上角为 (0,0)，地图 15×10、每格 64px。

## 0. 场景总览

```
标题 title.tscn
 ├─ 新游戏 ──→ 开场旁白 narration.tscn ──→ 战斗 battle.tscn（第一章）
 ├─ 继续游戏（有存档、且没打完第七章时出现）──→ 战斗（存档所在的章节：回合检查点或章节开场）
 ├─ 选择章节（打到过第二章后出现）──→ 战斗（所选章节的开场，用那时的队伍）
 ├─ 语言切换（中 / 英）
 └─ 菜单（系统菜单：继续、音乐音量、音效音量）

战斗 battle.tscn（第 1–7 章共用）
 ├─ 胜利 ──→ 结算层「进入下一章」/「回到标题」（第七章只有「回到标题」）
 └─ 战败 ──→ 结算层「重开本关」/「回到标题」

第一章 ─→ 第二章 ─→ 第三章 ─→ 第四章 ─→ 第五章 ─→ 第六章 ─→ 第七章（第一篇完）─→（后续章节制作中）
队伍、等级、道具、金钱一路继承（§11）
```

- 逻辑分辨率 1280×720 横屏。地图铺满整屏（比屏幕小的一维居中，比屏幕大就卷动），没有常驻的顶栏和侧栏，信息都放在浮动小窗里。
- 安全区：左右 64、上下 48；贴边按钮再内缩到 80；所有按钮最小热区 48px。
- 输入统一走 `PointerInput`：鼠标左键 = 触摸点按 = 「确认」；鼠标右键 / Esc / Android 返回 = 「后退」。

## 1. 标题画面（`title.gd`）

**画面**：近黑底色，24 颗橙色余烬粒子从下往上飘（出顶后回到底部随机位置）。中间大字「炎烬之誓」，副标「Emberflame Oath · 战棋原型」。右侧 280×360 金边框里是缇娅立绘。底部小字「第一篇 · 灰烬之芽（第 1–7 章，原型 v0.3）」。播放地图 BGM。

**按钮**（中间一列，自上而下）：

| 按钮 | 出现条件 | 行为 |
|---|---|---|
| 继续游戏 | `user://save.cfg` 存在，且没打完第七章 | 读档：回到存档里那一章的回合检查点；章节刚打完时则从下一章开头打起 |
| 新游戏 | 总是 | 无存档：直接开始；有存档：弹确认「开始新游戏会覆盖当前存档，确定吗？」→ 确定后删存档 → 开场旁白 |
| 选择章节 | 打到过第二章 | 弹出已到达章节的列表（「从所选章节的开头重新打起，之后的进度会被覆盖。」），选一章就用那一章开场时的队伍重打 |

左上「菜单」打开系统菜单（标题页隐藏「回到标题」按钮）；右上切换中英文，语言写入 `user://settings.cfg`。

**后退键**的层级：系统菜单开着 → 关菜单；确认框 / 章节列表开着 → 关掉它；都没有 → 打开系统菜单。

## 3. 战斗场景的通用流程（`battle.gd`）

五章共用同一个战斗场景。章节差异全在 `chapter1.gd`…`chapter5.gd` 的数据与事件钩子里，它们都继承 `chapter_base.gd`（默认钩子、胜负条件、对话 / 说得 / 支援的通用流程、旗标存读）。

### 3.1 进场

1. 有待读档就先读存档里的战役进度；章节取战役当前章（调试 / 测试可用 `queue_chapter` 直接指定）。
2. 建地图：`Board` 读入章节的 ASCII `MAP` 和高度 `LEVELS`，渲染三层——`MapTiles` 静态图块、`MapFx` 水波 / 火苗 / 烟、氛围层（云影、调色、暗角；火场章节压暗偏橙并加余烬粒子）。
3. 存档是本章的回合检查点 → 按存档还原单位与旗标，直接进入「待命」。否则按章节 `UNITS` + 队伍名单生成单位（§11），播开场剧情；剧情后如果有顺延的剧情转职（§10），先补上。
4. 播地图 BGM。有撤离点的章节在地图上用金框标出。

### 3.2 屏幕布局

火纹式浮动小窗（`scripts/map_hud.gd`），半透明、不吃点击，总是停在**光标的另一侧**（光标在左半屏就停右边，反之停左边），都在安全区内：
- **目标窗**（上）：章节名、「第 N 回合 · 我方回合 / 敌方回合」、金钱、本章胜利 / 败北条件。
- **单位窗**（目标窗下面，光标下有单位或选中单位时出现）：立绘 + 名字 / 等级 / 职业 / 阵营、HP / EXP、能力、武器、武器等级、道具。
- **地形窗**（下）：【地形名】高度 Lv、守备 / 回避、回复地形的回复量、撤离点标记。
- **提示条**（底部居中）：随状态变化的一行操作提示。
- **下拉菜单**：行动菜单贴着单位弹出（右侧放不下就放左侧）；**空地上点一下**（没有拖动地图）弹地图菜单：回合结束 / 显示（隐藏）危险范围 / 菜单（系统菜单）。点到菜单外的地图 = 取消，所以不再有「返回」按钮。
- **战斗预报**：竖排小窗，上面是对方、下面是自己，停在目标的另一侧。
- **出击准备**：右侧安全区内的半透明面板，这时信息窗固定停在左边。
- **对话框**：底部停靠，左侧 124px 立绘，名字按角色着色，打字机效果。

### 3.2b 新手教程（`scripts/tutorial.gd`）

- **开场询问**：第一章开场剧情后问「要看新手教程吗？」，答案记在 `Campaign.flags["tutorial"]`（新游戏才会再问）。
- **分步引导**（第一章第 1–2 回合）：屏幕上方的教程条一步步说做什么，金框标出要点的格子；玩家做到了自动进下一步，不锁操作，可以随时【跳过教程】：
  1. 点缇娅（金框）→ 2. 点蓝格移动（建议走到桥头前）→ 3. 行动菜单选【待机】→ 4. 巴尔托照做 → 5. 全员行动完自动进入敌方回合 → 敌方回合说明 → 6. 点敌人看威胁范围 / 地图菜单看危险范围 → 教程完成。
- **情境提示**（开了教程才有，每条只弹一次，看过的记在 `Campaign.flags["tips_seen"]`）：战斗预报、武器克制、地形、经验与升级、访问、对话与说得、道具与永久死亡、增援、首领、出击准备、商店、武器耐久、救出、支援、魔法与治疗、中立单位、宝箱。
- **教程手册**：地图菜单【教程】随时翻看全部条目。
- battle 在选人、行动菜单、行动结束、回合切换、预报、升级、增援、悬停等处调用 `tut(名字, 数据)` 通知教程。

### 3.2c 地图商店（`scripts/shop_window.gd`）

- 地图上的 `Y` 武器店、`V` 道具店（站上去回避 +10）：我方单位站上去，行动菜单出现【武器店】/【道具店】，打开商店窗口。
- 左边货架：点一下买进这个人的背包（满了送进道具库）；右边是他的背包，点一下半价卖出（按剩余耐久折算，专属武器不收）。
- 关店时做过买卖就算这个人这回合行动结束；什么都没买卖则回到行动菜单。
- 章节用 `shops()` 给出 `{格子: [物品 id, ...]}`。有地图商店的章节，出击准备里不再开商店（东西要到地图上的店里买）。
- 第一章村里有道具店 (7,1)（伤药）和武器店 (14,3)（铁剑、铁枪、铁斧、手斧、铁弓）。

### 3.3 回合循环

```
开场剧情 → [我方回合开始] → 我方逐个行动 → 全员行动完（或地图菜单「回合结束」）
        → [敌方回合] → 回到 [我方回合开始]（回合数 +1）
每次战斗后、每个我方单位行动结束后、每个我方回合开始时都检查胜负 → 胜利 / 战败结算
```

**我方回合开始**依次做：
1. 所有存活单位（含敌方）取消「已行动」灰色。
2. 回合数 +1（第一回合除外），横幅「第 N 回合 · 我方回合」，音效 phase。
3. 支援点结算：每个支援对如果此刻相邻，点数 +1；刚好攒满时提示「X 与 Y 的羁绊加深了……（相邻时可用【支援】）」。点数跨章节保留。
4. 胜负检查（守关章在这里判定「撑够回合」）。
5. 章节回合事件（增援、剧情，见各章）。
6. 进入「待命」，自动写本章检查点。

**敌方回合**：
1. 清掉所有高亮与危险范围，横幅「敌方回合」，等 0.9 秒。
2. 按单位列表顺序，每个存活敌人：
   - AI 决策（见 §5）。
   - 光标跳到它身上；若它要移动或攻击，先亮出它的移动范围 0.25 秒。
   - 沿路径走过去（每格 0.09 秒，森林 / 废墟等 2 消耗地形放慢 35%，边走边转身、脚下扬尘）。
   - 有目标就开战（完整战斗演出）；敌方治疗者则走过去治疗同伴（绿色飘字「HP +N」）。
   - 变灰，间隔 0.3 秒到下一个。
3. 全部行动完 → 下一个我方回合。

### 3.4 我方单位的一次完整行动

```
待命 ──点我方未行动单位──→ 选择移动
选择移动 ──点蓝格──→（走路动画）→ 行动菜单
行动菜单 ──攻击──→ [多武器时] 选武器 → 选目标 → 战斗预报 → 确定 → 战斗演出
         ──治疗──→ 选相邻受伤的同伴 → 回血 → 结束行动
         ──访问 / 对话 / 支援 / 说得──→ 剧情 → 结束行动
         ──道具──→ 选道具 → 使用 → 结束行动
         ──待机──→ 结束行动
```

1. **待命**：
   - 点我方未行动单位 → 选中（单位小跳一下）。
   - 点敌人 → 显示它的威胁范围（移动范围 + 移动后能打到的格子，红色）。
   - 点空地 → 清高亮。
   - 按 T 或地图菜单「显示危险范围」→ 开关全体敌人的威胁范围（红色虚线外轮廓）。
2. **选择移动**：蓝色 = 能到的格子，红色 = 移动后能攻击但走不到的格子。光标在蓝格上移动时，从单位脚下画出火纹式路径箭头。
   - 点蓝格 → 沿最短路径走过去。
   - 点另一个未行动的我方单位 → 改选它。
   - 点其他地方 / 后退 → 取消选择。
3. **行动菜单**（贴在单位旁边），按条件出现：

| 选项 | 出现条件 |
|---|---|
| 攻击 | 有能攻击的武器就出现（只带杖的修女没有）；当前位置打不到任何敌人时置灰 |
| 治疗 | 带治疗杖；身边没有受伤的同伴时置灰 |
| 访问 | 站在民居 H 上且这间没访问过 |
| 对话 | 章节判定有可对话的相邻伙伴（每对每章一次，见各章） |
| 支援 | 支援点已攒满且伙伴相邻、尚未解锁 |
| 说得 | 相邻有本单位能招募的敌人 |
| 道具 | 身上有道具 |
| 待机 | 总是 |

   后退 = 撤销移动：单位以 0.6 倍时长沿原路走回起点，重新进入「选择移动」。
4. **攻击**：
   - 有多把武器（巴尔托：银枪 / 投枪）时先选武器，按钮显示「武器名 (攻X 命Y)」，打不到目标的武器置灰。
   - 选目标：只高亮能打到的敌人。
   - 点目标 → **战斗预报**面板，左右两栏各写：名字 Lv 职业、HP、武器、攻击（追击时 ×2）、命中、必杀；防守方无法反击时写「（无法反击）」。确定 / 取消。
5. **战斗结算后**：阵亡单位淡出缩小 0.5 秒 → 我方参战者（主动攻击或被打后存活）获得经验并飘字「EXP +N」→ 满 100 升级，弹出升级面板 1.5 秒（逐项「+1」，全没涨写「（能力没有提升……）」）→ 章节战后事件 → 胜负检查 → 单位变灰。
6. 全员行动完：提示「全军行动完毕……」，0.6 秒后自动进入敌方回合。也可随时从地图菜单「回合结束」提前结束。

**道具**：目前只有伤药（恢复 10 HP，用掉即消失）。绿色飘字「HP +10」，占用本回合行动。

**治疗**：治疗量 = 杖的回复量 8 + 治疗者的力；我方治疗者每次 +12 经验（会升级）。

### 3.5 后退键的层级

系统菜单开着 → 关菜单；处在选择移动 / 行动菜单 / 选武器 / 选目标 / 道具菜单，或待命时地图上有高亮 → 后退一层；否则 → 打开系统菜单。下拉菜单开着时点到菜单外、选目标 / 选格子时点到无效格，也算后退一层。剧情、战斗演出、敌方回合中不响应。

**系统菜单**打开时暂停整个场景树：继续 / 回到标题 / 音乐音量 / 音效音量（音量存进 `user://settings.cfg`）。

### 4.3 公式

```
伤害 = 威力 + 力 + (克制时 +1) − 对方守备 − 对方脚下地形守备
命中 = 武器命中 + 技×2 + 相克×10 − 对方速×2 − 对方脚下地形回避   (0~100)
居高临下：所在高度更高的一方 命中 +10、伤害 +1
支援加成：已解锁支援的伙伴在相邻格 → 自己命中 +5、对方对自己命中 −5
追击：速度差 ≥4 的一方再打一次
必杀率 = 技/2 + 武器必杀，必杀伤害 ×3
```

- 出手顺序：攻击方 → 防守方反击 → 追击（攻击方速度快 4 以上则攻击方追击，否则防守方快 4 以上则防守方追击）。任一方 HP 归零立即结束。
- 命中和必杀各自独立掷骰。

**经验**

```
基础 = clamp(10 + (对方等级 − 自己等级) × 3, 1, 60)
击杀 +15；击杀 BOSS 再 +25
自己等级高于对方：每高 1 级 −3，最低 1
治疗：每次 +12
```

我方主动攻击时攻击者拿经验；敌方回合我方被打后存活，也按同样公式拿经验（反击杀敌算击杀）。每 100 升一级，各项按成长率逐项掷骰 +1。

## 5. 敌方 AI（`ai.gd`）

- **不动的单位**（布洛克、马尔科、霍克、巴雷特）：不动，只在原地能打到人时攻击，挑分数最高的目标。

- **普通敌人**：
  1. 枚举自己移动范围内每一格 × 每个我方单位 × 每把武器，计算
     `分数 = 伤害 × 命中/100 + (能一击打死则 +100) − 对方反击伤害 × 0.3`，
     选分数最高的「站位 + 目标」去打。
  2. 哪儿都打不到 → 走到离最近我方单位曼哈顿距离最近的格子，不攻击。
- 用哪把武器：在选好的站位上挑期望伤害最高的。

## 11. 战役进度、存档与续关（`campaign.gd`、`campaign_save.gd`）

**队伍名单**（`Campaign.roster`）：每个我方单位一条完整存档（等级、经验、能力、成长率、武器、道具、支援关系），外加状态：

- 章节胜利：存活的我方满血写回名单，金钱、支援点数一起带走，推进到下一章。

**存档**：单存档位 `user://save.cfg`，载荷里带完整战役进度。两种存档点：
1. **章节检查点**：每个我方回合开始、回合剧情放完时写入，带本章全部单位状态和章节旗标。「继续游戏」回到该回合开始。
2. **章节开场**：章节胜利后写入下一章的开场。「继续游戏」从下一章开头打起。
- 每章开场时的名单快照都存下来：「重开本关」回到本章开场时的队伍；标题「选择章节」可以回到打到过的任一章开头重打（之后的进度作废，会先提示）。
- 打完第七章：结算写「（后续章节制作中）」，只能回标题；存档标为通关，标题不再显示「继续游戏」，只留「选择章节」。
