> 本文按 `scripts/` 里的实际实现整理，不是设计愿景。设计大纲见 `design.md`。
> 数值、坐标、台词条数都以代码为准；坐标写作 (列 x, 行 y)，左上角为 (0,0)，地图 15×10、每格 64px。

## 0. 场景总览

```
标题 title.tscn
 ├─ 新游戏 ──→ 开场旁白 narration.tscn ──→ 战斗 battle.tscn（第一章）
 ├─ 继续游戏（有存档、且没打完第五章时出现）──→ 战斗（存档所在的章节：回合检查点或章节开场）
 ├─ 选择章节（打到过第二章后出现）──→ 战斗（所选章节的开场，用那时的队伍）
 ├─ 语言切换（中 / 英）
 └─ 菜单（系统菜单：继续、音乐音量、音效音量）

战斗 battle.tscn（第 1–5 章共用）
 ├─ 胜利 ──→ 结算层「进入下一章」/「回到标题」（第五章只有「回到标题」）
 └─ 战败 ──→ 结算层「重开本关」/「回到标题」

第一章 ─→ 第二章 ─→ 第三章 ─→ 第四章 ─→ 第五章 ─→（后续章节制作中）
队伍、等级、道具、金钱一路继承（§11）
```

- 逻辑分辨率 1280×720 横屏。地图区在左（960×640，顶栏下方 y=48 起），右侧 320px 是信息栏。
- 安全区：左右 64、上下 48；贴边按钮再内缩到 80；所有按钮最小热区 48px。
- 输入统一走 `PointerInput`：鼠标左键 = 触摸点按 = 「确认」；鼠标右键 / Esc / Android 返回 = 「后退」。

**按钮**（中间一列，自上而下）：

| 按钮 | 出现条件 | 行为 |

## 3. 战斗场景的通用流程（`battle.gd`）

五章共用同一个战斗场景。章节差异全在 `chapter1.gd`…`chapter5.gd` 的数据与事件钩子里，它们都继承 `chapter_base.gd`（默认钩子、胜负条件、对话 / 说得 / 支援的通用流程、旗标存读）。

### 3.1 进场

1. 有待读档就先读存档里的战役进度；章节取战役当前章（调试 / 测试可用 `queue_chapter` 直接指定）。
2. 建地图：`Board` 读入章节的 ASCII `MAP` 和高度 `LEVELS`，渲染三层——`MapTiles` 静态图块、`MapFx` 水波 / 火苗 / 烟、氛围层（云影、调色、暗角；火场章节压暗偏橙并加余烬粒子）。
3. 存档是本章的回合检查点 → 按存档还原单位与旗标，直接进入「待命」。否则按章节 `UNITS` + 队伍名单生成单位（§11），播开场剧情；剧情后如果有顺延的剧情转职（§10），先补上。
4. 播地图 BGM。有撤离点的章节在地图上用金框标出。

### 3.2 屏幕布局

- **顶栏**：章节名 ·「第 N 回合 · 我方回合 / 敌方回合」· 金钱；右侧「危险范围 (T)」「回合结束」按钮。
- **右侧信息栏**：顶部常驻本章胜负条件（每条最多两行，例如第一章「胜利 击败所有敌人」/「败北 缇娅或巴尔托阵亡」）。中间显示光标下的内容：
  - 有单位：立绘（有立绘的角色）+ 名字 / 等级 / 职业 / 阵营、HP / EXP、力技速守移、武器、道具。
  - 空地：【地形名】高度 Lv、守备 / 回避加成。
  - 底部常驻「返回」「菜单」。
- **底部提示条**：随状态变化的操作提示。
- **对话框**：底部停靠，左侧 124px 立绘，名字按角色着色，打字机效果。

### 3.3 回合循环

```
开场剧情 → [我方回合开始] → 我方逐个行动 → 全员行动完（或点「回合结束」）
        → [敌方回合] → 回到 [我方回合开始]（回合数 +1）
每次战斗后、每个我方单位行动结束后、每个我方回合开始时都检查胜负 → 胜利 / 战败结算
```

**我方回合开始**依次做：
1. 所有存活单位（含敌方）取消「已行动」灰色。
2. 回合数 +1（第一回合除外），横幅「第 N 回合 · 我方回合」，音效 phase。
3. 支援点结算：每个支援对如果此刻相邻，点数 +1；刚好攒满时提示「X 与 Y 的羁绊加深了……（相邻时可用【支援】）」。点数跨章节保留。
4. 胜负检查（守关章在这里判定「撑够回合」）。
5. 章节回合事件（增援、剧情，见各章）。
6. 进入「待命」，自动写本章检查点。

**敌方回合**：
1. 清掉所有高亮与危险范围，横幅「敌方回合」，等 0.9 秒。
2. 按单位列表顺序，每个存活敌人：
   - AI 决策（见 §5）。
   - 光标跳到它身上；若它要移动或攻击，先亮出它的移动范围 0.25 秒。
   - 沿路径走过去（每格 0.09 秒，森林 / 废墟等 2 消耗地形放慢 35%，边走边转身、脚下扬尘）。
   - 有目标就开战（完整战斗演出）；敌方治疗者则走过去治疗同伴（绿色飘字「HP +N」）。
   - 变灰，间隔 0.3 秒到下一个。
3. 全部行动完 → 下一个我方回合。

### 3.4 我方单位的一次完整行动

```
待命 ──点我方未行动单位──→ 选择移动
选择移动 ──点蓝格──→（走路动画）→ 行动菜单
行动菜单 ──攻击──→ [多武器时] 选武器 → 选目标 → 战斗预报 → 确定 → 战斗演出
         ──治疗──→ 选相邻受伤的同伴 → 回血 → 结束行动
         ──访问 / 对话 / 支援 / 说得──→ 剧情 → 结束行动
         ──道具──→ 选道具 → 使用 → 结束行动
         ──待机──→ 结束行动
```

1. **待命**：
   - 点我方未行动单位 → 选中（单位小跳一下）。
   - 点敌人 → 显示它的威胁范围（移动范围 + 移动后能打到的格子，红色）。
   - 点空地 → 清高亮。
   - 按 T 或点「危险范围」→ 开关全体敌人的威胁范围（红色虚线外轮廓）。
2. **选择移动**：蓝色 = 能到的格子，红色 = 移动后能攻击但走不到的格子。光标在蓝格上移动时，从单位脚下画出火纹式路径箭头。
   - 点蓝格 → 沿最短路径走过去。
   - 点另一个未行动的我方单位 → 改选它。
   - 点其他地方 / 后退 → 取消选择。
3. **行动菜单**（贴在单位旁边），按条件出现：

| 选项 | 出现条件 |
|---|---|
| 攻击 | 有能攻击的武器就出现（只带杖的修女没有）；当前位置打不到任何敌人时置灰 |
| 治疗 | 带治疗杖；身边没有受伤的同伴时置灰 |
| 访问 | 站在民居 H 上且这间没访问过 |
| 对话 | 章节判定有可对话的相邻伙伴（每对每章一次，见各章） |
| 支援 | 支援点已攒满且伙伴相邻、尚未解锁 |
| 说得 | 相邻有本单位能招募的敌人 |
| 道具 | 身上有道具 |
| 待机 | 总是 |

   后退 = 撤销移动：单位以 0.6 倍时长沿原路走回起点，重新进入「选择移动」。
4. **攻击**：
   - 有多把武器（巴尔托：银枪 / 投枪）时先选武器，按钮显示「武器名 (攻X 命Y)」，打不到目标的武器置灰。
   - 选目标：只高亮能打到的敌人。
   - 点目标 → **战斗预报**面板，左右两栏各写：名字 Lv 职业、HP、武器、攻击（追击时 ×2）、命中、必杀；防守方无法反击时写「（无法反击）」。确定 / 取消。
5. **战斗结算后**：阵亡单位淡出缩小 0.5 秒 → 我方参战者（主动攻击或被打后存活）获得经验并飘字「EXP +N」→ 满 100 升级，弹出升级面板 1.5 秒（逐项「+1」，全没涨写「（能力没有提升……）」）→ 章节战后事件 → 胜负检查 → 单位变灰。
6. 全员行动完：提示「全军行动完毕……」，0.6 秒后自动进入敌方回合。也可随时点「回合结束」提前结束。

**道具**：目前只有伤药（恢复 10 HP，用掉即消失）。绿色飘字「HP +10」，占用本回合行动。

**治疗**：治疗量 = 杖的回复量 8 + 治疗者的力；我方治疗者每次 +12 经验（会升级）。

### 3.5 后退键的层级

系统菜单开着 → 关菜单；处在选择移动 / 行动菜单 / 选武器 / 选目标 / 道具菜单，或待命时地图上有高亮 → 后退一层；否则 → 打开系统菜单。剧情、战斗演出、敌方回合中，「返回」按钮不响应。

**系统菜单**打开时暂停整个场景树：继续 / 回到标题 / 音乐音量 / 音效音量（音量存进 `user://settings.cfg`）。

## 4. 战斗规则（`combat.gd`、`game_data.gd`、`board.gd`）

### 4.1 移动

- 四方向 BFS。进入一格的消耗 = 地形消耗 + 爬升层数 ×2（下坡不加价）。
- 敌方单位挡路；友方可以穿过但不能停在其上。
- 守点单位（BOSS）`stationary`：永远不移动。

**地形表**

| 符号 | 地形 | 可走 | 消耗 | 守备 | 回避 |
|---|---|---|---|---|---|
| `.` | 平原 | ✔ | 1 | 0 | 0 |
| `R` | 道路 | ✔ | 1 | 0 | 0 |
| `F` | 森林 | ✔ | 2 | 0 | +10 |
| `H` | 民居 | ✔ | 1 | 0 | +5 |
| `B` | 木桥 | ✔ | 1 | 0 | 0 |
| `f` | 农田 | ✔ | 1 | 0 | 0 |
| `g` | 高地 | ✔ | 1 | 0 | +5 |
| `s` | 沙滩 | ✔ | 1 | 0 | 0 |
| `C` | 焦土 | ✔ | 1 | 0 | 0 |
| `Z` | 废墟 | ✔ | 2 | +1 | +5 |
| `~` 河流 / `M` 山地 / `W` 水井 / `X` 崖壁 / `E` 火焰 | | ✘ | — | — | — |

### 4.2 武器

| 武器 | 类型 | 威力 | 命中 | 必杀 | 射程 |
|---|---|---|---|---|---|
| 铁剑 | 剑 | 5 | 90 | 5 | 1 |
| 炎刃 | 剑 | 7 | 90 | 5 | 1 |
| 银枪 | 枪 | 12 | 80 | 5 | 1 |
| 投枪 | 枪 | 7 | 70 | 0 | 1–2 |
| 铁斧 | 斧 | 7 | 75 | 0 | 1 |
| 战斧 | 斧 | 9 | 65 | 0 | 1 |
| 铁弓 | 弓 | 6 | 80 | 5 | 2 |
| 钢剑 | 剑 | 8 | 75 | 0 | 1 |
| 细剑 | 剑 | 6 | 95 | 10 | 1 |
| 铁枪 | 枪 | 7 | 80 | 0 | 1 |
| 钢枪 | 枪 | 10 | 70 | 0 | 1 |
| 治疗杖 | 杖 | 回复 8 | — | — | 1（只能治疗，不能攻击或反击） |

（手斧、短弓已登记数据，暂时没有角色使用。）

- 相克：剑克斧、斧克枪、枪克剑。弓不参与相克。
- 弓手站在高度 ≥2 的格子上，射程 +1（变成 2–3）。
- 防守方自动选一把能打到当前距离的武器反击，没有就不能反击（例如弓手被贴脸、剑士被弓手隔一格射）。

### 4.3 公式

```
伤害 = 威力 + 力 + (克制时 +1) − 对方守备 − 对方脚下地形守备
命中 = 武器命中 + 技×2 + 相克×10 − 对方速×2 − 对方脚下地形回避   (0~100)
居高临下：所在高度更高的一方 命中 +10、伤害 +1
支援加成：已解锁支援的伙伴在相邻格 → 自己命中 +5、对方对自己命中 −5
追击：速度差 ≥4 的一方再打一次
必杀率 = 技/2 + 武器必杀，必杀伤害 ×3
```

- 出手顺序：攻击方 → 防守方反击 → 追击（攻击方速度快 4 以上则攻击方追击，否则防守方快 4 以上则防守方追击）。任一方 HP 归零立即结束。
- 命中和必杀各自独立掷骰。

**经验**

```
基础 = clamp(10 + (对方等级 − 自己等级) × 3, 1, 60)
击杀 +15；击杀 BOSS 再 +25
自己等级高于对方：每高 1 级 −3，最低 1
治疗：每次 +12
```

我方主动攻击时攻击者拿经验；敌方回合我方被打后存活，也按同样公式拿经验（反击杀敌算击杀）。每 100 升一级，各项按成长率逐项掷骰 +1。

### 4.4 典型数值（第一章初始状态、平地）

| 交战 | 攻方伤害 / 命中 / 次数 | 反击伤害 / 命中 / 次数 |
|---|---|---|
| 缇娅（铁剑）→ 山贼 | 9 / 100 / ×2（共 18，山贼 22 血打不死） | 8 / 55 / ×1 |
| 缇娅 → 布洛克 | 6 / 100 / ×1 | 14 / 51 / ×1（两下就能打死 20 血的缇娅） |
| 巴尔托（银枪）→ 山贼 | 18 / 82 / ×2（两下都中就击杀） | 5 / 73 / ×1 |
| 巴尔托（银枪）→ 布洛克 | 15 / 80 / ×2（共 30，布洛克 34 血） | 11 / 69 / ×1 |

### 4.5 战斗特写演出（`combat_scene.gd`、`combat_fighter.gd`）

每次交战（含敌方回合）都会进入横版特写。角色是原创 GBA 火纹风像素条带（`art/combat/fe/`，由 `tools/pixelart/fe_combat.py` 生成），每套有待机、跑、普攻、必杀、受击、倒地六个动作，普攻和必杀是两套不同的动作。

1. 切到战斗 BGM，白闪；按防守方脚下地形选四层视差背景（草地 / 森林 / 焦土；表里没有的地形默认草地），配环境粒子。
2. 双方从屏幕两侧跑步入场，镜头从右往中间收。
3. 每次出手：
   - **必杀蓄力**：背景压暗（角色不暗）、出手方发金光、大字「必 杀 !」、镜头推近；弓手身前先聚一圈光。
   - 近战跑到对方面前出招，到动作的出手帧才结算；弓手原地拉弓放箭，箭飞到才结算。必杀箭更大、发金光并拖光点。
   - 缇娅的必杀动作带橙色残影，这是主角专属。
   - 命中：顿帧、受击方闪白、震屏（必杀更重并全屏白闪）、火花、伤害数字、击退；HP 条在命中当帧开始掉。
   - 命中特效按角色区分（Ninja Adventure CC0 刀光帧）：

| 角色 | 普攻 | 必杀 |
|---|---|---|
| 缇娅 | 弧形刀光 | 火色大弧斩 + 十字斩 + 光环 |
| 巴尔托 | 斩痕 | 蓝白大弧斩 + 火花爆 |
| 山贼 | 双弧刀光 | 大回旋斩 + 圆斩 |
| 头目（布洛克 / 马尔科） | 大弧刀光 | 脚下爆炸 + 橙色冲击环 + 刀光 |
| 探子 | 斩痕 | 二连斩 + 十字斩 |
| 弓手 | 小光环 | 金色火花爆 + 光环 |

   - 未命中：「MISS」，受击方后撤闪避。
   - 打完后跳归位，压暗和镜头复原。
4. 阵亡方播倒地动作后淡出；整个特写淡出，切回地图 BGM。
- 底部双方面板：名字、武器、HP 数字与带刻度的 HP 条（我方蓝底、敌方红底）；右侧 HIT / DMG / CRT（追击时 DMG 后面带 ×2）。

## 5. 敌方 AI（`ai.gd`）

- **不动的单位**（布洛克、马尔科、霍克、巴雷特）：不动，只在原地能打到人时攻击，挑分数最高的目标。

- **普通敌人**：
  1. 枚举自己移动范围内每一格 × 每个我方单位 × 每把武器，计算
     `分数 = 伤害 × 命中/100 + (能一击打死则 +100) − 对方反击伤害 × 0.3`，
     选分数最高的「站位 + 目标」去打。
  2. 哪儿都打不到 → 走到离最近我方单位曼哈顿距离最近的格子，不攻击。
- 用哪把武器：在选好的站位上挑期望伤害最高的。

## 11. 战役进度、存档与续关（`campaign.gd`、`campaign_save.gd`）

**队伍名单**（`Campaign.roster`）：每个我方单位一条完整存档（等级、经验、能力、成长率、武器、道具、支援关系），外加状态：
- `active` 在队；`away` 剧情离队（艾德里克第 3 章后、巴尔托第 4 章后、哈洛和托比第 5 章开场）；`dead` 阵亡（永久死亡，之后的章节不再出场）。
- 章节开场：章节写了位置的我方单位按名单生成；名单里在队、但章节没写位置的（例如托比）依次放到备用格；名单里没有的我方单位只有「本章加入」的（艾德里克）才生成。
- 章节胜利：存活的我方满血写回名单，金钱、支援点数一起带走，推进到下一章。

**存档**：单存档位 `user://save.cfg`，载荷里带完整战役进度。两种存档点：
1. **章节检查点**：每个我方回合开始、回合剧情放完时写入，带本章全部单位状态和章节旗标。「继续游戏」回到该回合开始。
2. **章节开场**：章节胜利后写入下一章的开场。「继续游戏」从下一章开头打起。
- 每章开场时的名单快照都存下来：「重开本关」回到本章开场时的队伍；标题「选择章节」可以回到打到过的任一章开头重打（之后的进度作废，会先提示）。
- 打完第五章：结算写「（后续章节制作中）」，只能回标题；存档标为通关，标题不再显示「继续游戏」，只留「选择章节」。
- 语言和音量另存在 `user://settings.cfg`，与进度无关。

## 13. 现状与设计不一致 / 待补的地方

1. **新角色美术**：第 3–5 章 11 个新角色 / 敌人没有专属像素图和立绘（见 §12）。
2. **觉醒顺延看不到兑现**：按现在的经验曲线，缇娅到第 5 章大约 Lv7–9，觉醒会顺延；第 6 章还没做，所以目前的内容里缇娅一直是剑士。
3. **金钱没有用处**：只能攒（第 3 章还给 400），没有商店或整备。
4. **出击整备没做**：第 3–5 章是名单里所有在队成员全部出击，不能选人和布阵（大纲规定第 6 章起开放简易整备）。
5. **离队角色回归时的等级补正**没做（大纲第五节）。
6. **难度只做过粗调**：自动试玩（我方也交给 AI）跑通了第 2–5 章的流程；AI 操作的我方会无脑冲锋，常常两三回合内减员。人工试玩的手感还需要实际打一遍确认。
7. 打完第五章后，「继续游戏」不再出现，只能从「选择章节」重打。
