> 截至 2026-10-24，main 分支 `d4e249e`

## 1. 一句话

致敬 GBA《火焰之纹章：烈火之剑》的回合制战棋（SRPG），Godot 4.7 开发，手机横屏（Android）优先。
全三篇 30 章已经从头到尾可玩，中英双语，美术和音频全部原创或使用 CC0 素材。

**当前状态**：内容完整的可玩原型。经过三轮 QA 修复（卡关、数值、手机体验、存档安全），全量冒烟测试通过。
还没有正式立绘，没有上架包，隐藏篇和二周目没做。

## 2. 游戏内容

### 世界观

卡尔迪亚大陆。官方历史说，八百年前炎之巫女失控，召唤「不灭之火」烧毁了半个大陆，八位英雄用八件圣器把火封印。
此后火焰魔法被圣焰教会垄断，民间私藏火种是重罪。

真相（后期揭示）：失控的是初代大司祭莫尔甘，他想窃取炎龙之力；巫女是牺牲自己协助封印的人。
教会篡改了历史，莫尔甘本人靠灰烬傀儡技术活了八百年。

## 3. 玩法系统

**战斗核心**
- 武器三角；魔法打魔防。
- 特效武器：弓打飞行，破甲剑打重甲，拒马枪打骑马，守护之火打炎龙。
- 追击：速度差 ≥4。必杀伤害 ×3，必杀率扣防守方技巧的 1/4。
- 地形加成，高低差，武器耐久，武器等级 E–S。
- 经验按实际强度等级计算：上级职业 +20 级，剧情觉醒的炎刃使 +10 级。满级 Lv20。
- 转职道具需要 Lv10 以上；剧情转职有缇娅觉醒、第 28 章艾德里克立誓。

**同伴与剧情**
- 永久死亡：
  - 对后续主线没有戏份的同伴，倒下即阵亡。
  - 还有戏份的同伴「转幕后」：重伤撤退，剧情里仍然在，但不能再出击。各人的分界章节见 `scripts/fates.gd`。
  - 三主角倒下直接败北。
- 休闲模式：新游戏时选择，之后不能改。倒下的同伴下一章归队，主角倒下仍然败北。
- 离队与回归：回归时自动补等级到队伍平均水平；长期离队的人至少补到默认阵容的能力。
- 说得 / 对话招募：
  - 敌将可以被说得加入。
  - 绿色第三方单位会在「友军回合」自己参战，用【对话】才会加入。
  - 头上的气泡提示「现在有人能去谈」。
- 支援：相邻作战积累点数，命中、回避、必杀随支援等级提升。

**地图行动**
- 访问民居、开宝箱（盗贼）、偷窃（盗贼）、开牢门（盗贼 / 刺客 / 钥匙）。
- 救出、放下、交给同伴。
- 战斗中交换物品；道具菜单里换装备。
- 地图上的武器店、道具店。
- 首领倒下后，身上的道具交给打倒他的人。

**章节之间**
- 出击准备：选人、布阵、物品、道具库、商店、危险范围。
- 竞技场：在 10 个大战前的章节开放，每次出击准备最多打 3 场。
- 大陆地图开场（只显示去过的地方），尾声剧情场景卡。

**界面辅助**
- 战斗预报：全中后的剩余 HP、击破、武器克制、特效。
- 危险范围：开关跨回合保留，自动刷新。
- 敌人能力画面：点两次敌人，或长按。
- 目标窗显示剩余敌人 / 剩余回合。

**节奏与设置**
- 战斗特写可以关闭，改为地图上的简易交锋；敌方回合可切换快速模式。
- 对话可跳过（连点两次）；新手教程（分步引导 + 情境提示 + 手册）。

**存档**
- 单存档位，但有回合开始快照，可以「重来本回合」，败北后也能回到本回合开始。
- 切后台和每个行动后自动写中断存档。
- 写入先写临时文件再改名，并保留一份备份。

## 4. 手机适配

- **画面**：1280×720 横屏，`canvas_items` + `expand`。
  - 宽屏手机（20:9）上地图铺满整屏；1280 设计的界面居中，底色延伸到两边。
  - `edge_to_edge` 让画面延伸到刘海、挖孔区域。
- **安全区与尺寸**：左右 64、上下 48；按钮热区 ≥56 逻辑像素；正文字号 18–20。
- **触控**：
  - 松手才算点击，所以选中单位后可以拖动地图。
  - 长按单位看能力；第二根手指 = 取消。
  - 信息窗旁有常驻的【菜单】【危险】【下一个】按钮。
- **防误触**：回合结束（还有人没动）、回到标题、重来本回合、选择章节、卖装备中的武器、竞技场开打，都要二次确认。
- **Android 返回键**：逐层关闭当前界面，最后打开系统菜单。

## 5. 美术与音频

| 类别 | 来源 | 生成方式 |
|---|---|---|
| 地图图块 | CC0：Ninja Adventure（Pixel-boy、AAA） | `art/cc0/ninja_adventure/`，未改动只改名 |
| 地图小人（蓝 / 红 / 绿三色） | 原创像素（GBA 火纹风） | `tools/pixelart/fe_units.py` + `fe_art*.py` |
| 战斗特写角色 | 原创像素：头、躯干手画，四肢按骨架栅格化 | `tools/pixelart/fe_combat.py` + `fe_combat_art*.py` |
| 战斗背景 | 原创，8 套地形，4 层视差 | `tools/pixelart/combat_bg.py` |
| 对话立绘 | 原创像素，**暂时共用较多，计划换掉** | `tools/pixelart/fe_portraits.py` |
| 图标、标题主视觉 | 原创像素 | `tools/pixelart/app_icon.py`、`title_art.py` |
| 音效与配乐 | 程序合成，无第三方素材 | `tools/generate_audio.py`（`extra` 只生成后补部分） |

配乐共 7 首：第一 / 二 / 三篇地图曲、战斗、首领战、剧情、终章。
关键剧情（埃德蒙之死、缇娅被擒、炎龙觉醒、莫尔甘倒下）有闪光、震屏、换曲演出。台词可以带 `fx` 标记。

## 7. 开发与测试

- **引擎**：Godot 4.7.2，路径 `D:\tools\godot\Godot_v4.7.2-stable_win64_console.exe`。新增 class_name 脚本、图片或音频后，先跑一次 `--headless --import`。
- **冒烟测试**（在 `ember_oath` 目录下）：
  - `godot --path . res://tools/smoke_runner.tscn`：全量测试，约 40 分钟，必须 `ALL PASS` 才合并。
  - `SYSTEMS=1`：只跑系统检查（几分钟）。
  - `CHAPTERS=4,6 TURNS=8`：单章自动试玩。
  - `CAMPAIGN=1`：章节衔接。
  - `DEMO=1`：演示节奏，配合 `--write-movie x.avi --fixed-fps 20` 录像（`demo_videos/` 里有样片）。
  - 同一时间只能跑一个 Godot 实例，因为存档文件共用。
- **自动试玩说明**：
  - 用每章的默认阵容和一个简单 AI 打前几回合，日志里的 `[FALL]` / `[DEFEAT]` 反映难度。
  - 全量测试的随机序列是固定的，前面多加测试会改变后面章节拿到的随机数。单章的胜负要多跑几次才能判断。
- **翻译**：新的中文字面量要进 `locale/ui.csv`（键 = 中文），格式 `"中文","中文","English"`。
- **分支流程**：功能分支 → 跑全量测试 → `git merge --squash` 到 main → 推送。
